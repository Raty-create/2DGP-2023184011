# PRD: Drill #9 - 소년 상하좌우 이동 및 방향 바꾸기

## 개요
상하좌우 방향키를 사용하여 소년 캐릭터를 이동시키고, 이동 방향에 따른 애니메이션을 재생하는 기능 구현

## 요구사항

### 기능 요구사항
1. **상하좌우 이동** (3점)
   - 방향키(←, →, ↑, ↓) 입력으로 소년 이동
   - 좌우 이동 시 해당 방향 이동 애니메이션 재생
   - 상하 이동 시 기존 좌우 방향 유지하며 이동 애니메이션 재생

2. **IDLE 애니메이션** (1점)
   - 이동 키를 누르지 않을 때 IDLE 애니메이션 재생
   - 마지막 이동 방향(좌/우)을 유지하며 해당 방향 IDLE 애니메이션 재생

3. **화면 경계 제한** (1점)
   - 화면 경계에 도달하면 더 이상 이동하지 않음
   - 캐릭터가 화면 밖으로 나가지 않도록 제한

### 기술 요구사항
- 스프라이트 시트: `animation_sheet.png` 사용
- 배경: `TUK_GROUND.png` 사용
- 캔버스 크기: 1280 x 1024 (TUK_WIDTH, TUK_HEIGHT)

### 애니메이션 시트 구조 (animation_sheet.png)
- 행 0 (y=0): 왼쪽 이동 애니메이션 (100x100, 8프레임)
- 행 1 (y=100): 오른쪽 이동 애니메이션 (100x100, 8프레임)
- 행 2 (y=200): 왼쪽 IDLE 애니메이션 (100x100, 8프레임)
- 행 3 (y=300): 오른쪽 IDLE 애니메이션 (100x100, 8프레임)

## 구현 계획
1. 기본 프로젝트 설정 (캔버스, 이미지 로드)
2. 이벤트 처리 시스템 구축
3. 좌우 이동 입력 처리
4. 상하 이동 입력 처리
5. 캐릭터 상태 관리 (위치, 방향, 프레임)
6. 이동 로직 구현
7. 애니메이션 분기 처리 (이동/대기, 방향별)
8. 화면 경계 체크
9. 테스트 및 검증
